# Idea factory — 500+ dealer-positioning / market-structure ideas, one locked protocol (2026-10-09, before any data)

**Why.** The gamma-regime → range study (DESIGN_gamma_range.md) was the first idea to pass. Its recipe was: a mechanism
with a predicted sign, a feature known at the prior close, an outcome the next day, controls for what is already
known, an audit before one run. This file applies that recipe to every idea in `idea_registry.json` (generated by
`idea_registry.mjs`, committed with this file **before any data is downloaded**). With ~500 tests, about 25 would
pass a 5% bar by luck, so the protocol adds a false-discovery correction and an untouched holdout.

## Data
- **UW greek exposure by strike** (`/api/stock/{T}/greek-exposure/strike?date=D`; call/put gamma, delta, charm,
  vanna per strike, priced at day D's close — verified by audit 2026-10-09), every trading day 2023-11-08 →
  2026-10-08, for 25 tickers:
  SPY QQQ IWM DIA SMH XLK XLF XLE XLV XLY XLI XLP XLU GLD TLT AAPL MSFT NVDA AMZN META GOOGL TSLA AMD AVGO JPM.
  Collector `uw_greeks_collect.mjs` → `.cache/uwgreeks/{T}.jsonl` (strikes within ±30% of that day's close).
- **UW daily OHLC**, regular-session rows only (`market_time === 'r'`).
- **VIX daily close:** Cboe `VIX_History.csv` (identical to FRED VIXCLS).
- **Timing:** every feature uses data through the close of day d−1; the outcome is day d (or d … d+4).

## Periods
- **Build:** 2023-11-08 → 2025-06-30. **Holdout:** 2025-07-01 → 2026-10-08 (never used for stage 1).
- Known contamination: idea `G01×R1` (gamma balance → range) was already measured on 2025-08 → 2026-07; it is flagged
  `seen` and reported, but excluded from the holdout count of new validations.

## Each hypothesis
`outcome_d = a_ticker + β · feature_{d−1} + controls + e`, pooled over tickers (ticker fixed effects).
- Feature and outcome winsorized at the build-period 1st/99th percentiles (per ticker for features); the feature is
  standardized per ticker with build-period mean and s.d. (holdout uses the same build-period numbers).
- Standard errors: Driscoll–Kraay (Newey–West on date-summed scores), lag 5.
- **Predicted sign** from the registry: `+`, `−`, or `?` (two-sided, no sign claimed).

### Outcomes and controls
| id | outcome (day d) | controls |
|---|---|---|
| R1 | ln(range / prior close) | ln prior-day range, ln 20-day mean range, ln VIX |
| R2 | ln(mean range over d … d+4) | same as R1 |
| S1 | trendiness \|close − open\| / range | prior-day trendiness, ln 20-day mean range, ln VIX |
| D1 | open → close return ÷ 20-day mean range | prior-day close → close return |
| D2 | close → close return ÷ 20-day mean range | prior-day return |
| D3 | overnight gap (open ÷ prior close − 1) ÷ 20-day mean range | prior-day return |
| D4 | 5-day return (close d+4 ÷ close d−1 − 1) ÷ 20-day mean range | prior-day return |
| P1 | pull toward the d−1 gamma king: (\|open − K\| − \|close − K\|) ÷ open ÷ 20-day mean range | \|open − K\| ÷ open |

## Stage 1 — build period
p-value one-sided in the predicted direction (`+`/`−`) or two-sided (`?`). **Benjamini–Hochberg at q = 0.10** across
all registered hypotheses. Survivors go to stage 2.

## Stage 2 — holdout (the validation)
Each stage-1 survivor is re-estimated on the holdout with the build-period winsorizing/standardizing numbers.
**Validated** if the holdout coefficient has the stage-1 sign and passes **Benjamini–Hochberg at q = 0.10 across
the stage-1 survivors** using one-sided holdout p-values in that sign.
Reported for every validated idea: holdout effect in plain units, index-ETF-only result (SPY QQQ IWM DIA), share of
tickers with the same sign, and whether it adds anything beyond the strongest validated idea in its outcome family
(joint regression, reported only).

## Run discipline
Registry + this file committed before download. Engine `idea_factory.mjs` audited independently before the single
run; fixes logged below. Output `shadow/results_idea_factory/`. Research only — nothing live changes.
